## 1. Guiding principles
1. **Data-driven**: spells, enemies, items, quests, dialogue, regions, cinematics are Resources/JSON.
2. **Decoupled via `EventBus` signals**; UI never mutates state directly.
3. **Separation**: rendering / logic / UI / data.
4. **Scripts under ~300 lines**; composition over inheritance.
5. **Reproducible art**: every PNG is generated by scripts in `tools/art/` and committed.
6. **Always runnable** after each milestone.
7. **Juice is architecture**: hit-stop, shake, light, particles, sound and camera are driven by one `FeelDirector`, not sprinkled ad hoc.
8. **Spectacle budget**: 60 FPS on integrated GPUs. Epic ≠ heavy; fake it with layered sprites, additive blends and shaders.

## 2A. CODEBASE MAP (file-by-file reference)

> This is the exact codebase the agent must create. File names, `class_name`s and public APIs below are the contract; add files only when needed, and update this section when you do.

### 2A.1 Dependency rules (who may call whom)
```
UI scenes ──listen──▶ EventBus ◀──emit── gameplay scripts
UI scenes ──call────▶ Managers (GameState, InventoryManager, QuestManager…)  (never mutate fields directly)
Gameplay (player/enemies/bosses) ──call──▶ components (Health, Hitbox…) + FeelDirector + VFXManager + AudioManager
Managers never reference scenes in scenes/UI or scenes/world by path (use EventBus or SceneManager registry)
data/ + resources/ are read-only at runtime (except save data)
```
Rules: no circular autoload dependencies; autoload order in project.godot = `EventBus, GameState, InputConfig, SaveManager, AudioManager, VFXManager, FeelDirector, CinematicDirector, WeatherManager, SceneManager, InventoryManager, QuestManager, DialogueRunner`.

### 2A.11 Naming & code conventions (codebase-level)
- Files: `snake_case.gd/.tscn/.tres`; classes: `PascalCase`; signals past tense; constants `UPPER_SNAKE`; ids are `StringName` literals (`&"chaos_bolt"`).
- One scene = one primary script at the same relative path (`scenes/enemies/thorn_wraith.tscn` ↔ `scripts/enemies/thorn_wraith.gd`).
- Every script begins with a header comment: purpose, owner system, key signals.
- No `get_node("../..")`; use `@export var x: Node`/groups (`&"player"`, `&"enemy"`, `&"interactable"`).
- Group names, input actions, physics layers and animation names are centralized as constants in `scripts/managers/constants.gd` (`class_name C`).
- Animation naming: `{action}_{dir}` e.g. `walk_down`, `cast_bolt_left`; single-direction ones are `rupture`, `backlash`.

1. Data/resources + `constants.gd` → 2. managers → 3. components → 4. entities → 5. scenes/maps → 6. UI → 7. tests → 8. validation + art QA → 9. update CHANGELOG/README.

## 3. Project settings
- Viewport 480×270, stretch `viewport`, aspect `keep`, scale mode `integer`; default window 1440×810; F11 fullscreen with letterbox.
- Default texture filter Nearest; snap 2D transforms/vertices to pixel.
- Renderer: **Forward+ (or Mobile)** to allow glow/HDR bloom on magic; keep a `gl_compatibility` fallback toggle in settings that disables bloom and heavy shaders.
- Physics layers: `world, player, enemy, player_hitbox, enemy_hitbox, hurtbox, interactable, projectile, tk_object, trigger, decoy`.
- Input: WASD/Arrows move; LMB Chaos Bolt; Q Telekinesis; R Hex Veil; **E Scarlet Rupture**; Space dash; Shift sprint; F interact; Tab journal; Esc pause; F11 fullscreen. Rebindable via `InputConfig`.
- **Rendering stack**: game world renders into a `SubViewport` at 480×270 → post-process `ColorRect`/shader chain (bloom-lite, instability glitch, time-freeze, vignette) → upscaled with integer scale. This allows whole-screen shockwaves, desaturation and distortion without breaking pixel crispness.

## 5. Gameplay architecture

### 5.1 Player
`CharacterBody2D` → `AnimatedSprite2D` (+ separate `CapeSprite`, `AuraSprite`, `HairFX` overlays for power-tier visuals) · `HealthComponent` · `Hurtbox` · `SpellCaster` · `InteractionArea` · `PointLight2D` (crimson, intensity scales with instability) · `StateMachine` (idle, walk, run, dash, cast_*, hurt, backlash, dead, victory, cinematic).
8-way movement, sprint, dash with i-frames, pixel-rounded position. Responsive: input buffering (0.1s), coyote-style dash/cast cancel windows.

### 5.2 Combat core
`Hitbox` / `Hurtbox` / `HealthComponent` / `StatusEffects` / `DamageInfo` (amount, type, knockback, status, **feel_tier**). Damage types: CHAOS, TELEKINETIC, ILLUSION, PHYSICAL. Telegraph decals (animated pixel sprites, never raw polygons): ≥0.4s regular, ≥0.6s boss. No unavoidable damage.

### 5.3 Spells (`SpellResource`)
- **Chaos Bolt** – fast crimson projectile; tiers add pierce, split, chain-lightning arcs; each hit spawns shard debris.
- **Telekinetic Grasp** – energy tendrils; pull, lift, **slam into walls for bonus damage**, throw crates/statues/rubble; stun; manipulates puzzles and arena objects. Big-silhouette moments: lifting a stone golem's shield, ripping pillars from the floor.
- **Hex Veil** – decoy illusions, brief phase-shift, mirror-image barrage; enemies target decoys; at high tiers decoys *explode* in chaos.
- **Scarlet Rupture** – screen-filling ultimate: glyph circle charge → time-slow → shockwave ring → reality-crack flash. Consumes chaos charge. Cinematic-grade feel (`FeelDirector.impact(CATACLYSMIC)`).
- **Spell fusion (late-game upgrade layer)**: e.g., Bolt through a Veil decoy splits into a fan; Telekinesis-thrown objects ignite with instability. Creates build identity.

### 5.4 Chaos Instability
0–100. Thresholds (from `balance.json`): Stable <30 · Charged 30–60 (+dmg) · Volatile 60–90 (++dmg, reality distortions, enemies more aggressive) · Backlash at 100 (0.8s telegraph then radial blast + stun, reset to 40).
Visual tiers (all driven by `EventBus.instability_changed`):
- Tier 0: soft ember wisps on hands.
- Tier 1: crimson aura outline, cape flares upward, light radius up.
- Tier 2: floating glyph ring behind Wanda, ground cracks glow under her feet, tile flicker, chromatic split begins, music adds distortion layer.
- Tier 3: ghosted double-image, screen edge vein-glow, world desaturates except crimson, time micro-stutters, sub-bass rumble.
Management: movement/dash-cancel bleed, Veil upgrades, shrine cooling, specific skills.

### 5.5 Enemies
`EnemyResource` + state machine `idle→alert→chase→telegraph→attack→recover→stun/flee`. Types: Lesser Wraith, Hollow Wraith, Thorn Wraith, Mirror Wraith, Archive Sentinel, Rift Guardian. Add **elite variants** (palette-swapped + new attack) per region and **mini-boss ambushes** at hidden locations. Group AI roles (flanker, bruiser, caster) so fights read tactically.

### 5.6 Bosses (`boss_base.gd` + `PhaseResource`)
Each phase = HP threshold, attack set, arena change, music layer, intro/transition cinematic hook. Each boss has ≥12 animation states and a **signature mechanic** (Section 12). Boss HP bar is an ornate custom UI with phase pips.

## 6. World architecture
- Map scene: `TileMapLayer` ×N (ground/detail/walls/overhead), Y-sort objects, spawns, transitions, interactables, enemies, NPCs, `LightingController`, `CanvasModulate`, parallax, `WeatherManager` preset, region `Region` script.
- Handcrafted maps with landmarks, shortcuts, secrets, vistas. Minimums: Grove 3 · Cinderwake hub + 5 interiors + outskirts · Glassfen 4 + puzzle rooms + arena · Archive 4 wings + arena · Spire 3 chambers + arena.
- **Vista moments**: each region has ≥2 scripted camera reveals (slow pan to a giant landmark: the stopped clock tower, the Mirror Loom spanning the sky, the Archive's floating library core, the Spire piercing a frozen sky).
- Puzzle framework: root_bell, mirror_reflect (beam routing), tk_block, rune_sequence, time_phase_platforms, memory_echo.
- World reacts to progress: Cinderwake lanterns relight as quests complete; Glassfen reflections show alternate futures; Archive pages begin to turn; the sky actually **brightens a little** as the player nears the true ending path.

### 9.6 Lighting & atmosphere (where it becomes beautiful)

- **Volumetric faux-godrays**: additive pre-drawn shaft sprites, slow drift, dust motes crossing them.
- 3–4 layer **parallax** per region (sky bands, distant landmarks, mid mist, foreground framing foliage).
- **Weather/ambient** (`WeatherManager`): embers, spores, fireflies, mist, burning pages, falling sand/time-shards.
- **Heat/reality distortion** shader pockets near distortion zones.
- Dynamic shadows: simple blob/sprite shadows under actors; soft long shadows from big lights allowed if pixel-banded.
- Banded dithered pre-dawn sky backdrops (hand-authored 480×270) that subtly shift as story progresses.
- **Palette-locked bloom**: HDR glow only on magic/light sources, thresholded so the pixel grid stays crisp.

## 10. ASSET GENERATION TOOLCHAIN (`tools/art/`)
```
palette.py · pixel_lib.py (primitives, outline, shade, dither, mirror, hue-ramp, compose) · sprite_dsl.py (ASCII-grid → palette-key sprites + per-frame deltas)
gen_wanda.py · gen_npcs.py · gen_enemies.py · gen_bosses.py · gen_objects.py · gen_tileset_<region>.py · gen_vfx.py · gen_ui.py · gen_backgrounds.py · gen_portraits.py · gen_cutscene_art.py · gen_lightmaps.py
export_godot.py (SpriteFrames/TileSet .tres + atlas docs) · build_all.py (deterministic, seeded) · qa_art.py · preview.py (4× contact sheets + in-engine screenshot harness)
```
**Quality method**
1. Hand-authored pixel maps for all key silhouettes (Wanda's head/headpiece, enemies, boss parts, hero props). Procedural fill only for textures.
2. Layered compositing with offset-driven secondary motion.
3. Auto-shading with hue-shift, then manual touch-ups.
4. Deterministic seeds.
5. **Visual iteration loop (mandatory)**: generate → render contact sheet → *open and look at it* → critique (silhouette, palette, readability, consistency) → fix → repeat. Also capture **in-engine screenshots** (headless `--write-movie` or viewport `get_image()`) of each map and boss arena and review them in context with lighting on. Don't advance until it looks genuinely good.
6. A **style-lock reference sheet** (`documentation/art_previews/style_lock.png`) is made first (Wanda, one enemy, one tileset sample, one VFX) and every later asset is compared against it.

**`qa_art.py` gates**: dimensions vs ART_SPEC · palette membership (tolerance 0) · no stray semi-transparency · orphan-pixel detection · anchor stability ±1px · animation frame counts · contact sheets produced.
Fallback if Pillow unavailable: Godot headless `Image` scripts.

**Audio (`tools/audio/`)**: original synthesised audio (numpy+wave): region pad/drone loops, melodic motifs w/ reverb, **adaptive stem music** (base / tension / combat / instability-distortion / boss-phase layers crossfaded by `AudioManager`), synthesised SFX (bolt zaps, TK whooshes with pitch bend, glass shatter, clock ticks, rupture sub-boom). Log credits in `AUDIO_CREDITS.md`.

## 12. SPECTACLE BIBLE — the epic set pieces (must be built)

**Cinematic system** (`CinematicResource` timeline tracks: camera, actor anim, dialogue, music, shader, FeelDirector, flag). Letterbox bars, skippable, replayable from codex "Memories".

**Prologue — Hollow Grove**
- *Opening*: dark screen, a single crimson spark, rift tears open in pixel-shatter, Wanda falls through (cinematic anim), lands in a slow-mo camera push.

- **Boss — Hollow Warden**: colossal root-titan (128px, multi-part: two arms, torso, glowing core). Phases: (1) slow root slams with telegraphed ground decals; (2) summons Lesser Wraiths and roots that snare; (3) core exposed after Wanda uses telekinesis to rip off armour bark. Arena: roots erupt from the floor and rearrange the layout.

**Act I — Cinderwake**
- *Reveal*: pan across the dead village to the stopped clock tower; embers fall upward.
- *Set piece — The Hour Repeats*: during a quest, a village moment loops while Wanda stands inside the loop; she has to disrupt its causal chain (puzzle + emotional beat with Elara).
- **Boss — Thornbound**: a twisted giant fused with a thorn-wraith swarm; vines rip through the street, partially destroying the arena; phase 3 turns the village square into a thorn labyrinth. Weakness: lantern-light + burn from instability.

**Act II — Glassfen**
- *Reveal*: infinite mirrors on the horizon; reflections show alternate Wandas who do different things — a visual jolt.
- *Set piece — Mirror Cascade*: crossing a giant fractured mirror bridge that shatters behind her; reflections hunt her; Mirror Wraiths emerge from glass.
- **Boss — Mirror Saint**: floating saint with orbiting mirror-shard wings that reflect Wanda's own spells back; the player must use Hex Veil to make the Saint attack its own reflection. Phase 3: arena becomes a hall of mirrors with a true-one among false-ones puzzle-fight. Defeat reveals Aster's history via memory-echo cutscene.

**Act III — Ember Archive**
- *Reveal*: a library the size of a city, floating between moments; pages burn upward in glowing streams.
- *Set piece — The Collapsing Stacks*: escape sequence across falling platforms and telekinetic-lifted bridges while the archive reshuffles around her.
- **Boss — Ashen Scribe**: robed figure writing reality into existence; paints hazards, erases floor tiles, writes enemies into being; Wanda must use telekinesis on giant floating tomes/quills to rewrite his sentences against him. Phase 3: pages swirl into a storm; Scribe's script is corrupted and becomes dangerous.

**Final Act — Hourglass Spire**
- *Ascent*: gravity-shifting stairs, sand falling upward, time shards, glimpses of the lost futures (Wraiths' origins) in glittering fragments.
- *Confrontation*: **Aster Vale** — dialogue duel where the player's choices shape the final battle's variations.
- **Final Boss — Aster Vale / The Stillkeeper**: 4 phases.
  1. *The Gatekeeper*: elegant, time-stop pulses, hourglass bullet patterns, rewinds Wanda's position (dodge by Veil).
  2. *The Rewinder*: arena periodically rewinds hazards; Wanda must break anchor nodes with telekinesis.
  3. *The Eternal*: floor flips, gravity shifts, massive hourglass halo, screen drains of colour except crimson.
  4. *The Choice*: arena becomes a reflective void; Aster stops attacking and offers the final decision; ending branches here. Different endings alter the last musical cue and ending cinematic.
- Ending cinematics fully animated with camera moves and music.

**Hidden / secret set piece — The Rewoven Dawn**: only reachable with the story flags; Wanda reweaves the anchors (a stunning sequence: threads of crimson light spiralling up from the anchors into the sky; the sky finally brightens through pixel-banded colour gradient into real dawn).

**Recurring spectacle tools**: shockwave rings, time-slow on kill-shots (rare), dramatic boss intro title cards, "last-hit" slow-mo, level-up burst, shrine-activation ripple.
